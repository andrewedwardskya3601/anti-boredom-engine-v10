## What Is ANTI-BOREDOM_ENGINE?

ANTI-BOREDOM_ENGINE is a web application for gamified task injection. Instead of leaving you with an empty screen, it presents organized activity prompts through separate lanes and intensity settings. The result is a structured workflow wrapped in a cyberpunk terminal aesthetic.

The project is intended for anyone looking to make routine activities feel less repetitive, discover different activity patterns, or introduce more momentum into their workflow. Algorithmic task expansion, score tracking, and synth audio work together to provide progression signals and visual feedback in one interactive browser experience.

- Draws from more than 600 distinct operations to provide a wide range of tasks

- Adds synth audio to reinforce the immersive interface
- Uses streak multipliers to track progress through scoring
- Adapts to web browsers with a responsive neon terminal presentation

## How to Use

Load the application in a browser and begin by selecting the lane that best fits the activity you want to receive.

The usual sequence is:

1. Choose Social, Solo, or Active
2. Set the intensity to Normal or Chaos
3. Generate tasks from the available operation collection
4. Work through the result while monitoring the score and streak multiplier
5. Use the synth audio and terminal-style presentation as part of the interface

Because the layout is built for quick task-type changes, switching between lanes and intensity modes does not require moving to another tool.

## Configuration

The primary controls are available through the web interface. When hosting or modifying the project, the main HTML and script files generally contain the definitions for task pools, lane behavior, intensity handling, and audio responses.

Example configuration:

      "lane": "Solo",
      "intensity": "Normal",
      "audio": true,
      "theme": "neon-terminal"
    }

When making source changes, ensure that task definitions continue to match the display logic so lane selection and scoring behave consistently.
